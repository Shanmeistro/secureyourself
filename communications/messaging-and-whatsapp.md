# Messaging and WhatsApp

Last reviewed: `[YYYY-MM-DD]`. Features and menu names change; verify in the app. Applies equally to Signal, iMessage, Telegram, etc.

## Checklist

- [ ] Two-step verification / registration PIN enabled; PIN stored in `[PASSWORD MANAGER]` (`Needs verification`)
- [ ] Recovery email set where the app offers one
- [ ] Linked devices reviewed; unknown ones removed
- [ ] Privacy settings: who sees profile photo, last seen, groups (`Needs verification`)
- [ ] Disappearing messages: used where it reduces risk; not a guarantee (screenshots, backups)
- [ ] Chat backups: know where stored and whether encrypted
- [ ] Never share verification codes, even with "friends" (a common takeover technique: verify via a different channel)

## Number-change / recovery plan

1. Before changing number: use the app's change-number feature; update 2-step recovery.
2. Keep the old number until accounts that use it for recovery are updated.
3. If a number is lost: contact the carrier, then re-register the apps; warn contacts out-of-band.
4. Carrier PIN / port-out protection (`Needs verification`).

If an account is taken over: [account compromise](../incident-response/account-compromise.md).
